Reading config files in Python

5 min read · configparser · standard library

The configparser module reads INI-style files. Create a parser, call read() with the file name, and then look values up by section and key. Missing keys raise KeyError unless you pass a fallback.

import configparser

config = configparser.ConfigParser()
config.read("settings.ini")
port = config.getint("server", "port", fallback=8080)

getint(), getfloat() and getboolean() convert the value for you, so "8080", "0.5" and "yes" come back as 8080, 0.5 and True.
